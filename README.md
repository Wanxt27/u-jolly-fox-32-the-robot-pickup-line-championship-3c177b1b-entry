A make.fun entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).

`main.ts` (Node 22+, stdlib only) writes exactly one line — 91 characters — to `/output/entry.txt`:

> Are you a CAPTCHA? Because ever since I met you, I've been trying to prove I'm not a robot.

The joke grows out of being a machine: a CAPTCHA exists to tell robots apart from humans, so a robot begging to prove it is *not* a robot turns its own machinery inside out. Classic pickup-line shape ("Are you a…?"), one sharp turn, nothing padded.

Run it with:

```sh
node main.ts
```
